# Experiment data

The files under `output/` are synthetic measurements generated by ParityLab. They contain packet recovery outcomes from virtual-time experiments, byte-decoder trials, and local loopback UDP transfers. They contain no captured Internet traffic or human participant data.

## Origin and collection

`python scripts/reproduce.py --calibration` generates the registered studies from deterministic payloads, published seeds, and configured impairment models. Each study's `manifest.json` records its settings, seed rules, source SHA-256 hashes, artifact hashes, and runtime information. The baseline and sensitivity studies use five seeds; socket evaluation uses three. Calibration retains raw erasure masks and policy training sequences. The reports retain negative performance outcomes and infeasible protection choices.

The studies are distinct samples:

| Directory | Records |
| --- | --- |
| `output/experiments` | 260 transfers |
| `output/studies/sensitivity` | 370 transfers |
| `output/studies/equal-overhead` | 160,000 paired decoder trials |
| `output/socket-evaluation` | 36 three-process transfers and received binary files |
| `output/congestion` | 70 runs with two flows each |
| `output/calibration` | 3,060,000 decoder trials and 225,000 estimated-policy trials |

The equal-budget study pairs identical erasure masks across codecs. Using the same seed across transport protocols matches configured conditions; different send schedules can consume different random draws. Real socket timings and process IDs depend on the operating system.

## Format and verification

JSON stores transfer settings, metrics and event records. CSV stores codec trials and summaries. Large congestion JSON, equal-budget CSV and calibration masks use gzip. Congestion and equal-budget manifests hash the uncompressed bytes; calibration hashes its compressed raw artifact. `python scripts/verify.py` checks source freshness, artifact hashes, counts and transfer integrity. Source hashes include exact file bytes, so Git preserves line endings.

Metric definitions are in [the model documentation](docs/model.md); conditions and measured comparisons are in [the report](docs/project-report.md). Means and sample standard deviations describe the configured seeds and are not confidence intervals. Do not pool separate studies as one sample.

## Use and limits

The data is intended for reproducing these experiments, teaching packet recovery, and checking alternative controllers under the recorded conditions. It does not represent Internet traffic, real users, peer interoperability or a production congestion controller. Independent and binary Markov loss models omit many path behaviors. Estimated risk intervals can miss, changing loss can violate stationary assumptions, and adaptive parity can reduce goodput. The small configured seed sets and finite trial budgets limit generalization.
