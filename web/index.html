    About this replay

    Timings, losses, and receiver state are recorded by the simulator. Positions on the link are illustrative. A received packet may wait for earlier packets before the application can read it. Space plays or pauses when focus is outside a control; R restarts and L seeks the next loss.

    How to read these results

    Goodput counts useful file bytes. Completion is when the receiver has the file; replay continues until the sender has its ACKs. Bars are scaled within each row. Each protocol uses the same settings and seed, but consumes random draws in a different order. Five-seed results show mean ± sample standard deviation, not a confidence interval or a significance test.
